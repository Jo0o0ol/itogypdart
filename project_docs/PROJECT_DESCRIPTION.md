# Описание предметной области

**BeanHouse** — информационная система кофейни.

Посетитель просматривает меню, использует поиск и фильтры, добавляет позиции в избранное и корзину, применяет промокод, оформляет заказ, отслеживает его состояние, бронирует столик и хранит любимый напиток в профиле.

Бариста управляет меню, категориями, ингредиентами и поставщиками, а также работает с очередью заказов: переводит их из нового состояния в приготовление, готовность и выдачу.

Администратор управляет пользователями и ролями, столиками, бронированиями, справочниками и просматривает сводные показатели.

## Бизнес-правила

- код позиции меню уникален;
- цена положительна;
- остаток не может быть отрицательным;
- один профиль принадлежит одному пользователю;
- количество гостей не превышает вместимость столика;
- два активных бронирования одного столика не должны пересекаться по времени;
- посетитель видит только свои заказы, брони и избранное;
- бариста не может изменять роли пользователей;
- физическое удаление разрешено администратору;
- логическое удаление скрывает запись из рабочих списков.

## Содержательная особенность

В проекте две особенности предметной области:

1. **Конструктор напитка** — рассчитывает объём, количество шотов эспрессо и цену с учётом размера, сиропа, альтернативного молока и дополнительного эспрессо.
2. **Проверка пересечения бронирований** — перед созданием брони система получает соседние интервалы с сервера и проверяет, свободен ли выбранный столик.
